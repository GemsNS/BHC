# BH Contracting — Walid Warehouse Private Presentation

Static, privately hostable one-page presentation for the Mount Uniacke warehouse exterior. Includes four siding application systems on the locked permit geometry, interactive GLB, verified site photography, dimensions, takeoff, contract review, editable DOCX forms, permit PDF, and 3D exchange files.

## Serving

Served from this app at `/presentations/walid` (password protected). For standalone hosting, upload this folder preserving `assets/` and `project-assets/`, then open `index.html` over HTTPS/HTTP (not `file://`).

## Field verification

Model, boards, takeoff, and elevations are for façade intent and coordination. Field-verify dimensions, openings, grade, substrate, cladding limits, products, flashings, and quantities before ordering or construction.
