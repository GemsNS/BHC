# Walid Warehouse Extension — Façade Design Brief

**Prepared for:** BH Contracting Ltd.  
**Project:** Warehouse Extension, 9 Alicia Scott Ave., Mount Uniacke, Nova Scotia  
**Design basis:** Issued-for-permit geometry, supplied construction photographs, and two user-provided façade reference boards  
**Status:** Façade design brief for project review

## Design Intent

The exterior concept uses a **dark charcoal vertical profile as the primary field**, with **warm cedar-tone wood-look siding as a controlled accent**. Black window, door, fascia, and trim components unify the two finishes. The concept is intentionally simple enough to install as repeated panel fields while giving the entrance and shop-door elevations a stronger architectural identity.

## Exterior Lighting Concept

Warm wall sconces are centered above or between the principal openings on the entrance and garage façades. Recessed or linear downlights are placed beneath the entrance canopy/portal. Lighting in the model is representational only and does not establish electrical locations, fixture ratings, photometrics, or code compliance.

## Site and Grade Treatment

The building shell follows the permit drawings, with the lower man door placed on the **left sidewall** near the garage corner to match the as-built site photo. The surrounding ground plane is a **continuous sloping driveway / grade** approximation (not outdoor stairs), fully exposing the lower level at the garage façade and rising toward the upper-grade entrance side.

## Chosen Editable Modeling Workflow

The primary source will be a **parametric JSCAD JavaScript model**. JSCAD is open-source, runs directly in a browser, accepts `.js` design files, and supports common exchange/export formats including STL, OBJ, DXF, SVG, X3D, AMF, and 3MF.[1] The browser workflow allows BH Contracting Ltd. to drag the supplied model file into the online editor and adjust named parameters without purchasing CAD software.[2]

The package will also include deterministic 2D SVG elevations and a browser-viewable 3D presentation file so the design can be reviewed without interpreting raw source code.
